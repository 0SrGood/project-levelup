# Level Up - Inscrições

Site do curso de desenvolvimento de jogos no Roblox Studio.

Página estática responsiva com a identidade visual da Level Up Academy, mascotes, apresentação dos recursos da plataforma e formulário integrado ao FormSubmit e WhatsApp.

O botão **Já sou aluno** abre o login em https://0srgood.github.io/levelup-academy-web/.

## Publicação

No GitHub, acesse Settings > Pages e selecione Deploy from a branch, branch main e pasta / (root).

## Conteúdo

Os arquivos `index.html`, `style.css`, `app.js`, imagens e a pasta `assets/` devem permanecer juntos na raiz do repositório. O arquivo `.nojekyll` desativa o processamento Jekyll. Não há etapa de build nem dependências para servir a página.

## Imagens

Veja `image-credits.txt`. O logotipo, o emblema e os mascotes vêm dos materiais da própria Level Up. A fotografia da apresentação é o quadro 16 do acervo enviado pelo responsável pelo site. As imagens foram otimizadas em WebP; as fontes DM Sans e Space Grotesk são servidas localmente.

Os exemplos do Roblox Studio têm atribuição junto à galeria. A ilustração da plataforma é identificada como ilustração, sem dados de alunos.
