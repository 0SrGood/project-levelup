# Project Level Up

Site do curso de desenvolvimento de jogos no Roblox Studio.

Página estática responsiva com formulário integrado ao FormSubmit, WhatsApp e Instagram.

## Publicação

No GitHub, acesse Settings > Pages e selecione Deploy from a branch, branch main e pasta / (root).

## Conteúdo

Os arquivos index.html, style.css, app.js e imagens devem permanecer juntos na raiz do repositório. O arquivo .nojekyll desativa o processamento Jekyll.
